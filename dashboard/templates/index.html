Known Limitations

LeakGuard is an MVP static analyzer with intentional trade-offs. Here's what it cannot do:

1. Inter-procedural Analysis

We don't track resources across function boundaries. If you pass a file handle to another function, we can't tell if that function closes it.

2. Object-Level Resources

Only local variables are tracked. Resources stored in class instances or collections are not analyzed.

3. Implicit Exception Paths

We detect explicit try/except blocks, but cannot predict which function calls might raise exceptions.

4. Complex Control Flow

Loops with breaks/continues and nested exception handlers are not fully analyzed.

These limitations are documented for transparency. We prioritize low false positives over exhaustive detection.
